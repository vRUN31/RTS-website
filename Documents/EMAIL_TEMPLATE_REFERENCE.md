## Color Coding System

### Status Colors

**Approved/Delivered (Green):**
- Header: Linear gradient `#10b981` → `#059669`
- Badge: Green gradient
- Accent: `#10b981`
- Highlight box: `#d1fae5` (light green background)

**In Transit (Blue):**
- Header: Linear gradient `#3b82f6` → `#2563eb`
- Badge: Blue gradient with pulse animation
- Accent: `#3b82f6`
- Highlight box: `#dbeafe` (light blue background)

**General:**
- Cards: `#f8f9fa` to `#e9ecef` gradient
- Text: `#333`, `#555`, `#666`
- Headers: `#1a1a1a`
- Footer: `#1a1a1a` background
- White: `#ffffff`

## Typography Scale

**Headers:**
- Email Title (H1): 28px, bold
- Section Title: 18px, bold
- Card Title: 16px, bold

**Body:**
- Greeting: 18px, semi-bold
- Main text: 16px, regular
- Info labels: 14px, regular
- Small labels: 12px, uppercase

**Line Heights:**
- Body: 1.6
- Headers: 1.2
- Labels: 1.0

**Font Family:**
```
'Segoe UI', Tahoma, Geneva, Verdana, sans-serif
```

## Responsive Behavior

### Desktop (>600px)
- 2-column grid for info cards
- Full-width route display
- Side-by-side CTA buttons

### Mobile (<600px)
- Single column layout
- Stacked info cards
- Vertical route display (arrow rotates 90°)
- Full-width CTA buttons

**CTA Buttons:**

## Template Variables

Each template uses dynamic data:

### Booking Approval
- `customerName` - Client's full name
- `bookingId` - Booking reference
- `sourceCity`, `destinationCity` - Route
- `distance` - Calculated from `analyzeTripDetails()`
- `estimatedTime` - Formatted duration
- `estimatedArrival` - Date + time
- `pickupDate` - Scheduled pickup
- `material`, `weight` - Cargo details
- `vehicleType` - Truck type
- `truckPlate` - Assigned vehicle
- `driverName`, `driverPhone` - Driver info
- `trackingUrl` - Dashboard link

### Trip Started
- All booking fields plus:
- `shipmentId` - Shipment ID
- `currentLocation` - (optional) Current city

### Trip Completed
- Similar to Trip Started but:
- `actualTime` - Calculated from timestamps
- `deliveryDate` - Actual delivery timestamp
- `documentsUrl` - Document download link
